# Data access

This public portfolio repository does not include source extracts, merged tables, or row-level movie records. The original analysis used data collected from publicly available web sources, but the public presentation keeps only the code, methodology, and aggregate results.

The original workflow combined:

- The Numbers for production budget and box-office data;
- IMDb-style metadata pages for movie characteristics and audience measures;
- Academy Awards history; and
- a public franchise/IP reference list.

If reproducing the workflow, source data should be collected and stored locally under `data/private/`. That directory is excluded from version control. Because websites and page structures change, rerunning the 2022 scraping workflow may require maintenance.
